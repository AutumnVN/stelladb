# Nazuna

Nazuna takes on the Main slot as a buffer for this team, providing high amounts of ATK% buff with **Fill the Gap** + **Cutie's Rally** and Skill Crit Rate with **Operation: Pandemonium**.

# Ann

Ann supports the team by giving a lot of Ventus DMG Taken debuffs and ATK% buffs.

# Rotation

### General Rotation
1. Nazuna Main Skill
2. Wait 2s then use Nazuka Supp. Skill + Ann Supp. Skill
3. Ensure that both Ann and Nazuka's Supp. Skills line up by using Ann’s skill only when Nazuka’s skill CD hits 4s.

### When to use Ultimate?
• Nazuna: After using her skill and ensure that it is timed 2s before using Nazuka's skill.
• Nazuka: When skill cooldown hits 10s.
• Ann: 1s before Nazuka's skill (but not at the same time as Nazuna's Ultimate)

### Tips
• Nazuna reloads faster if she is constantly moving.
• Nazuna restores energy faster if you cancel her reload animation by dashing.

__Additional Timings During Nazuka's Ultimate__
• Use Ann's skill when Nazuka's ultimate is at 24s CD (Nazuka skill: 4s CD)
• Use Nazuna's skill and ultimate when Nazuka's ultimate is at 22s CD (Nazuka skill: 2s CD)

__One, Two, Three Jump! Disc Effect Snapshot__
• This assumes that you have One, Two, Three, Jump! disc on Main slot.
• Nazuka’s Ultimate allows her next skill usage to carry over the disc’s snapshot benefits.
• Only use Nazuka's Ultimate just before her skill hits to snapshot the disc’s buff for maximum damage.
