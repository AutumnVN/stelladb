# Allie

Allie's Skill build revolves around two factors: 1) the typical Main Skill usage and 2) the Ultimate DMG to Skill DMG conversion done by **Clothesline Stance** to her Ult Phase 2. With the addition of **Quick Sweep**, her Main Skill can transform into Ult Phase 2 (Mini-Ult) after gaining 5 stacks of Sweep Mark. With that in mind, this is how the general rotation looks like: Main Skill → wait 2s → Mini-Ult → Main Skill.

Casting her Ultimate skill grants a 15s ATK% buff (+40% Aqua DMG at T1). You should fit in as many skills as possible during this period depending on your Main Skill availability:
• If Main Skill is on cooldown: Ultimate → Main Skill → Ult Phase 2 → Mini-Ult → Main Skill → Mini-Ult
• If Main Skill is ready: Main Skill → Ultimate → Mini-Ult → Ult Phase 2 → Main Skill → Mini-Ult

**★ Key Notes:**
• If you have Suntide Willow, you don't need a 2nd Crit Rate on her emblem at T1 to reach 100% Crit Rate.
• It's possible to gain Sweep Marks using Main Skill without dealing DMG if you proc **Sweep Dash**'s effect first.
• Try to stack **Clothesline Stance**'s Skill DMG buffs before entering the fight.
• **Mirror Blade** is capable of dealing massive burst damage that becomes better as its level increases.

# Suntide Willow

Suntide Willow is the core support of the team, providing a wide array of buffs and debuffs.

**★ Key Notes:**
• **Rhythm Surge** and **Prismatic Bubbles** provides a total of 30% Crit Rate buff for the team.
• **Engulfing Tide** expands her skill's radius further while giving Aqua DMG buff for the team.
• **Marine Justice** inflicts a good amount of Aqua DMG Taken debuff.
• **Balmy Surf** provides DEF PEN buff for the team.
• **Receding Echoes** provides Crit DMG buff for the team.

## Skill

1/1/10/10 (Support Skill > Ultimate)

@skill(Frolic in the Sea) @skill(Beach Warning) Prioritize upgrading **Frolic in the Sea (Support Skill)** first and **Beach Warning (Ultimate)** next since her Support Skill gives more buffs than her Ultimate.

You can comfortably stop at Level 7 if you're low on resources since her buff scaling is rather underwhelming compared to others.

# Donna - Sub-DPS Build

Donna's use-case in this team is to be a sub-DPS using her usual DPS build. She does not benefit much from the buffs given by Suntide Willow since she is a Skill DMG Trekker.

Do take note that you will want to have a built Donna in the first place if you want her to be a sub-DPS for this team.

**★ Key Notes:**
• You need 1 level of **Chilling Onslaught** for **Aquatic Assault** to function.

## Skill

1/1/10/1 (Support Skill only)

@skill(Tide Threader) **Tide Threader (Support Skill)** is Donna's primary damage source through its innately high multipliers. Its level also directly scales the damage dealt by **Unleashed Arrow** and **Arrowfall Reckoning**.

# Donna - Support Build

If you don't have a built Donna, that's fine, you can opt to build her with just potentials that can support Allie.

**★ Key Notes:**
• **Frostbitten Arrow** is the most important potential in this build due to its high amount of Aqua DMG Taken debuff.
• Make sure that Allie picks up the letters delivered by **Messenger Arrow**, otherwise it's pointless to have this potential.

# Teresa

If you don't have Donna, you can use Teresa instead but take note that she is far worse in Skill build than in Mark build.

**★ Key Notes:**
• **Isn't it Awesome** provides a 25% ATK SPD buff which is useful for Allie to charge the team's energy faster, provided that you have the shield intact.
