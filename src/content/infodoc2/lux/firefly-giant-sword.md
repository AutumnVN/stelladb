# Minova

Minova's role in this team is to provide Lux DMG Taken debuffs with her More Than Just Pretty potential. ★ Key Notes: • Space out Minova's Main Skill usage by only using each phase after every AA5 hit so More Than Just Pretty 's uptime is constantly active. • Minova's AA5 hit has a distinctive *ding* sound cue for you to easily determine when to use her Main Skill again. • Both Ashwind Rhythm and Light Burn are treated as QoL potentials in this case because they are only taken for their unique effects and not for the Skill DMG buff that they provide.

## Skill

Minova is relegated as a supporter for Firefly on this team so it's best to not upgrade any of her skills.

# Firefly

Currently in testing phase. Firefly's Giant Sword build relies heavily on Auto Attack DMG . This is currently her best solo DPS build because none of the current units have Lucent mark trigger (except Firefly herself on Main slot). ★ Key Notes: • Radiance Blade: Blazing Edge requires a full Lux team to function. • Luminous Onslaught requires consistent Mark triggers to stack its effects, which Minova cannot do so it is not included in this build.

## Skill

Starflare Pursuit (Support Skill) is the only important skill to max out as this is Firefly's prominent source of damage. Additionally, both Radiance Blade: Blazing Edge and Radiance Blade: Pursuing Slash 's DMG output scale with its level.

# Tilia

Tilia is a staple support for any Lux team currently, offering constant ATK% buffs and Lux DMG Taken debuffs for the team using her Support Skill and potentials. ★ Key Notes: • Blinding Beam gets a place as an optional potential for this team because Minova's raw Mark DMG is high (in fact, the highest in the game currently ). If you are forced to take a 5th Tilia potential, it's pretty much the last best choice .

## Skill

Aegis Intervention (Support Skill) provides an ATK% buff to the team when her skill deals DMG. This buff scales according to the level of the skill and thus, it is beneficial to upgrade it.
